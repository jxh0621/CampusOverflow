# 用户故事地图

## 横轴：用户活动序列

```
注册登录 → 浏览课程 → 浏览问题 → 提问 → 回答 → 互动（投票/评论）→ 采纳 → 声誉成长 → 搜索发现
```

## 纵轴：具体任务步骤

### 1. 注册登录
| 活动 | 用户故事 |
|---|---|
| 学生注册 | PB-05 注册/登录 |
| 加入课程 | PB-05 浏览课程并加入 |

### 2. 浏览问题
| 活动 | 用户故事 |
