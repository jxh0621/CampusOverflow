## 遇到的困难和解决方法

1. **问题：** 标签计数不对，编辑问题后标签数量没更新
   **解决：** 检查 QuestionCommandService 的 edit 方法，发现是旧标签没有 -1、新标签没有 +1，修复后就对了

2. **问题：** Docker Desktop 一直启动不了，卡 Starting 状态，集成测试跑不了
   **解决：** 先装了 WSL2，但还是不行，最后决定先不折腾 Docker，把单元测试跑通就行，集成测试后面再说

3. **问题：** 一开始不知道 PR 流程怎么走，直接在 main 上改代码
   **解决：** 后面专门走了一遍完整的 PR 流程演示（创建 feature 分支 → 推送 → 网页上创建 PR → 合并 → 清理分支），学会了标准流程

4. **问题：** 应用层之前没有测试，不知道怎么写
   **解决：** 参考了领域层测试的写法，自己写了 Reputation 和 Discovery 的应用层幂等测试，验证事件重放不会重复加分
