# CampusOverflow 上下文映射

## 子域划分

| 子域 | 类型 | 上下文 | 职责 |
|---|---|---|---|
| 身份与课程 | 支撑子域 | Identity | 用户注册、登录、课程管理、角色权限 |
| 课程问答 | 核心域 | Q&A | 问题、回答、投票、评论、采纳、教师认证 |
| 声誉与激励 | 核心域 | Reputation | 声誉账本、徽章、悬赏、排行榜、对账 |
| 内容发现 | 通用子域 | Discovery | 全文搜索、相关问题推荐、通知中心 |

## 上下文映射关系

```
Identity（上游/OHS）
  │
  ├── UserRegisteredEvent ──→ Reputation（开户）
  │
  └── IdentityApi（查询）
        │
        ├── Q&A（查询用户信息、课程权限）
        ├── Reputation（查询用户信息、课程权限）
        └── Discovery（查询用户信息）

Q&A（核心域/OHS）
  │
  ├── QuestionPostedEvent ──→ Discovery（更新搜索索引）
  ├── AnswerSubmittedEvent ──→ Discovery（通知）
  ├── AnswerAcceptedEvent ──→ Reputation（+15声誉） + Discovery（通知）
  ├── AnswerEndorsedEvent ──→ Discovery（通知）
  ├── VoteCastEvent ──→ Reputation（投票计分）
  ├── CommentPostedEvent ──→ Discovery（@提及通知）
  ├── ContentDeletedEvent ──→ Discovery（更新搜索索引）
  │
  └── QaQueryApi（查询）
        │
        ├── Reputation（悬赏时查询问题状态）
        └── Discovery（搜索时查询问题投影）

Reputation（核心域/OHS）
  │
  ├── BadgeAwardedEvent ──→ Discovery（通知）
  ├── BountyOpenedEvent ──→ Discovery（通知）
  ├── BountyAwardedEvent ──→ Discovery（通知）
  ├── BountyClosedEvent ──→ Discovery（通知）
  └── ReputationChangedEvent ──→ Discovery（排行榜更新）

Discovery（通用子域/遵奉者）
  │
  ├── 自有搜索投影（SearchIndex）
  ├── 自有通知模型（Notification）
  └── 订阅所有上游事件
```

## 共享内核（Shared Kernel）

- 领域异常体系：BusinessRuleException、NotFoundException、ForbiddenException、ConflictException
- Guard 断言工具
- Actor / Role 值对象
- IntegrationEvent 基类
- IntegrationEventPublisher 端口
- 分页 PageRequest / PageResult
- AuditTrail 端口
