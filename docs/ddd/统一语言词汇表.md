# CampusOverflow 统一语言词汇表

## 核心域术语

| 术语 | 英文 | 定义 |
|---|---|---|
| 问题 | Question | 学生提出的待解答内容，含标题、正文、标签、课程关联 |
| 回答 | Answer | 对问题的解答，Markdown 格式 |
| 投票 | Vote | 对问题或回答的点赞(+1)/点踩(-1)/撤销(0) |
| 采纳 | Accept | 提问者选定最佳答案，回答者+15声誉 |
| 教师认证 | Endorse | 教师/助教对优质回答的权威背书标记 |
| 评论 | Comment | 对问题或回答的简短讨论，支持@提及 |
| 标签 | Tag | 问题分类关键词，1-5个，如"数据结构""红黑树" |

## 声誉域术语

| 术语 | 英文 | 定义 |
|---|---|---|
| 声誉 | Reputation | 用户累计声望值，由所有账本流水之和 |
| 可用积分 | AvailablePoints | 可用于发起悬赏的积分 |
| 冻结积分 | FrozenPoints | 悬赏发起时冻结的积分，结算后扣除或退回 |
| 账本 | Ledger | 声誉流水记录，只追加，唯一键(eventId, userId, reason) |
| 徽章 | Badge | 成就标记，如"初露锋芒"(首次被采纳) |
| 悬赏 | Bounty | 提问者/教师发起的积分奖励，吸引优质回答 |
| 排行榜 | Leaderboard | 按周/月/学期/总榜展示声誉排名 |

## 发现域术语

| 术语 | 英文 | 定义 |
|---|---|---|
| 搜索投影 | SearchIndex | 问题的全文检索投影，支持中文ngram分词 |
| 通知 | Notification | 站内消息，含回答、采纳、认证、悬赏、徽章、@提及 |
| 相关问题 | RelatedQuestion | 基于标签相似度的推荐问题 |
