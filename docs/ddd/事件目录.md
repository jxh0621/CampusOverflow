# CampusOverflow 领域事件目录

## Identity 上下文发布

| 事件 | 发布时机 | 订阅者 |
|---|---|---|
| UserRegisteredEvent | 用户注册成功 | Reputation（开户） |

## Q&A 上下文发布

| 事件 | 发布时机 | 订阅者 |
|---|---|---|
| QuestionPostedEvent | 发布问题 | Discovery（更新搜索索引） |
| QuestionEditedEvent | 编辑问题 | Discovery（更新搜索索引） |
| AnswerSubmittedEvent | 提交回答 | Discovery（通知）、Reputation（FIRST_ANSWER徽章） |
| AnswerAcceptedEvent | 采纳最佳答案 | Reputation（+15声誉+悬赏结算）、Discovery（通知） |
| AnswerEndorsedEvent | 教师认证回答 | Discovery（通知）、Reputation（TEACHER_ENDORSED徽章） |
| VoteCastEvent | 投票/改投/撤销 | Reputation（投票计分） |
| CommentPostedEvent | 发表评论 | Discovery（@提及通知） |
| ContentDeletedEvent | 软删除问题/回答 | Discovery（更新搜索索引） |

## Reputation 上下文发布

| 事件 | 发布时机 | 订阅者 |
|---|---|---|
| ReputationChangedEvent | 声誉变动 | Discovery（排行榜更新） |
| BadgeAwardedEvent | 授予徽章 | Discovery（通知） |
| BountyOpenedEvent | 发起悬赏 | Discovery（通知） |
| BountyAwardedEvent | 悬赏结算 | Discovery（通知） |
| BountyClosedEvent | 悬赏到期关闭 | Discovery（通知） |

## 事件投递机制

- 事务性发件箱模式（ADR-002）
- OutboxRelay 每 500ms 轮询未投递事件
- 至少一次投递语义
- 消费者幂等：账本唯一键(eventId, userId, reason)、通知唯一键(sourceEventId, recipientId)
